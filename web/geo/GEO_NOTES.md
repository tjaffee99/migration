# Map geometry (`web/geo/`)

Geometry for the 1607–2024 year-slider map of migration to what is now the United States, plus the world "origins" map.
Everything here is generated by the scripts in `scripts/geo/` from the raw downloads in `data/raw/<source>/`.

## Files

| File | Size (gzip) | Contents |
|---|---|---|
| `us_historical.topo.json` | 386 KB (72 KB) | TopoJSON, one object `jurisdictions`: 486 polygons = 359 colony/state/territory versions + 107 context polygons (areas not yet in a US/colonial jurisdiction). Unprojected lon/lat (WGS84), quantization 1e5, 1,100 shared arcs. |
| `us_historical_years.json` | 242 KB (5 KB) | `{description, snapshot:"July 1", first_year:1607, last_year:2024, years:{"1607":[ids…], …}}`: the ids active on **July 1** of each year, including the `ctx_*` context ids. | `world.topo.json` | 115 KB (39 KB) | world-atlas 2.0.2 `countries-110m` (Natural Earth 1:110m). Objects `countries` (id = ISO 3166-1 numeric; properties `iso3, iso_numeric, name, ne_name`) and `land`. |

## Rebuild

```bash
cd scripts/geo && npm ci                  # mapshaper 0.7.89, d3-geo 3.1.1, topojson-client 3.1.0, playwright-core 1.64.1
bash build_all.sh [RENDER_DIR]            # download_raw.sh -> build_us_historical.mjs -> verify_us_historical.mjs
                                          # -> build_modern_states.mjs -> build_world.mjs [-> render_checks.mjs]
```
`unzip_lenient.py` extracts the AHCB zips. `US_AtlasHCB_Counties_Gen01.zip` has 19 KB of junk before its central directory, and Info-ZIP rejects it as a "possible zip bomb". The extractor walks the local headers and checks every CRC. The full build takes about 75 s.

## `us_historical.topo.json` properties

| key | meaning |
|---|---|
| `id` | AHCB state/territory version: `<AHCB ID>_v<VERSION>` (e.g. `va_state_v4`, `it_indianterr_v2`, `ak_district_v1`). County-derived colonial/revolutionary versions: `<key>_<YYYYMMDD start>` (e.g. `va_colony_16541231`, `new_netherland_16240501`, `pa_state1776_17760704`). Context: `ctx_<region>_<YYYYMMDD start>`. |
| `name` | Display name (AHCB `FULL_NAME` for 1783+; e.g. "Massachusetts Bay", "Carolina (North)" before 1712-01-24, "New Netherland (Dutch)", "Kingdom of Hawaii"). |
| `type` | `colony` · `state` · `territory` · `district` (DC, Alaska District 1884–1912, District of Louisiana 1804–05) · `unorganized` (AHCB "Unorganized Territory": e.g. Louisiana Purchase 1803–04, Indian Territory, Unorganized Federal Territory, Alaska Department, Hawaii Annexation 1898–1900, Erie Triangle) · `other` (Vermont Republic, Texas Republic, Deseret, Oregon Country, the AHCB "Uncertain Boundary Area", and all context polygons). |
| `start`, `end` | Inclusive validity dates, `YYYY-MM-DD`. AHCB's last date 2000-12-31 is written as **2024-12-31** and means "still current": no state boundary changed between 2001 and 2024 at this scale. |
| `fips` | 2-digit FIPS of the modern state this jurisdiction is the clear ancestor or main successor of; blank when there is none. States and colonies get their own state's code. Territories get the code of the state named after them (e.g. Missouri Territory → 29, Southwest Territory → 47, Orleans Territory → 22, Indian Territory → 40, Deseret → 49, Erie Triangle → 42, New Netherland → 36, New Sweden → 10, Plymouth → 25). Blank for Northwest Territory, Dakota Territory, Louisiana Purchase/District/Territory, Mexican Cession, Gadsden Purchase, Oregon Country / Oregon unorganized territory, Unorganized Federal Territory, Uncertain Boundary Area, Wisconsin Terr. de facto, and all context polygons. |
| `abbr` | AHCB `ABBR_NAME` (e.g. `VA`, `MI Terr`, `Indian Terr`), or a short code for colonies (`PLY`, `NN`, `NSw`, `NHav`, `EJ`, `WJ`). Empty for context polygons. |
| `src` | `ahcb_stateterr` (220), `ahcb_counties` (137: colonies/states dissolved from AHCB counties), `approx` (22: back-filled or synthesised, see below), `context` (107). |
| `note` | The AHCB `CHANGE` text for the version (1783+), or an explanation of the approximation or derivation. |
| `power`, `context` | Context polygons only: `context:true`, and `power` = `Spain`, `France`, `Great Britain`, `Great Britain (disputed)`, `Mexico`, `Russia`, `Hawaii`, or `''` (none / undetermined). |

Coverage is a snapshot for **every** year from 1607 (Virginia + context) to 2024. July 1 counts: 1610: 1 jurisdiction + 12 context · 1700: 13 + 12 · 1776: 13 + 12 (colonies, before July 4) · 1784: 16 + 11 · 1803: 22 + 10 · 1850: 37 + 3 · 1880: 50 + 1 · 1900: 52 · 1959: 51 (Alaska a state, Hawaii still a territory) · 2024: 51.

## Processing (`build_us_historical.mjs`)

1. **1783-09-03 → 2024**: all 220 AHCB `US_HistStateTerr_Gen01` polygons as they are, with properties remapped and end dates of 2000-12-31 extended to 2024-12-31. Areas outside the present-day US outline are clipped away: Oregon Country's British Columbia part, and the part of the Louisiana Purchase / District / Territory and Missouri Territory v1 north of 49°.
2. **1607 → 1783-09-02** (AHCB's state file starts at the Treaty of Paris): AHCB **historical counties** (incl. AHCB "non-county areas", colony-wide charter polygons, parishes and districts) are dissolved by jurisdiction. This happens on every date when a jurisdiction's county set changes (354 breakpoints). A version is kept only if the outline changes (395 candidates → 153 versions). Jurisdiction = AHCB `STATE_TERR` ("Virginia Colony" … then "Virginia" from 1776-07-04, "Vermont Republic", "Erie Triangle …"), with these splits: **Plymouth** (`mac_newplymouth`, and Plymouth/Barnstable/Bristol counties before 1691-10-07), **Province of Maine** (`mes_nca` "Maine", 1664–68), **East/West Jersey** (before 1702-04-15), **New Netherland** for NY/NJ/DE during the Dutch reconquest (1673-08-09 → 1674-11-09), and "Carolina (North/South)" names before 1712-01-24.
   These colonial shapes show the colony's **organized county area**, not its sea-to-sea charter claim. Virginia, for example, grows west county by county, and from 1778 its Illinois County covers the whole Northwest. Everything else is a context polygon.
3. **Back-fill / approximation rules** (`src:"approx"`, explained in `note`):

   | Jurisdiction | Period | Shape used |
   |---|---|---|
   | Virginia | 1607-05-14 → 1634-12-30 | AHCB 1634 (8 original shires) |
   | Plymouth | 1620-12-21 → 1630-01-12 | AHCB 1630 patent |
   | New Netherland | 1624-05-01 → 1664-09-07 | AHCB New York counties of 1683-11-01 (minus Cornwall/Dukes), + AHCB 1673 Delaware counties from 1655-09-15 |
   | Maryland | 1634-03-25 → 1638-01-23 | AHCB 1638 |
   | Connecticut | 1636-06-01 → 1665-01-04 | AHCB 1665 extent (1636–62) or 1662 charter (1662–65), minus the New Haven approximation |
   | Rhode Island | 1636-06-01 → 1644-03-13 | AHCB 1644 patent |
   | New Haven | 1638-04-24 → 1665-01-04 | AHCB New Haven County as created 1666 |
   | New Sweden | 1638-03-29 → 1655-09-14 | AHCB 1673 New Amstel + Upland counties |
   | New York | 1664-09-08 → 1683-10-31 | AHCB 1683 counties (AHCB maps no NY counties except Cornwall before 1683) |
   | New Jersey | 1664-09-08 → 1676-06-30 | AHCB 1676 East + West Jersey |
   | Delaware | 1664-09-08 → 1673-09-11 | AHCB 1673 |
   | South Carolina | 1670-04-01 → 1682-05-09 | AHCB 1682 |
   | Georgia | 1733-02-12 → 1758-03-16 | AHCB 1758 parishes |

4. **Context polygons** ("not yet part of the US"). The modern outline (dissolved AHCB 2000 polygons, which match the county coastline exactly) is split into fixed acquisition regions built from AHCB polygons. In priority order: Hawaii, Alaska, Florida (`fl_uft`), Texas (`tx_republic`), Gadsden (`gd_purchase`), Mexican Cession (`mx_cession`), Red River basin (`ub_area`), Louisiana Purchase (`la_purchase`), Oregon Country (`or_country`), the 1783 US ("east"), the West Florida strip (what Orleans Territory 1804 adds), and "other" (one 5,500 km² leftover in central Colorado that no AHCB acquisition polygon covers).
   The context pieces are recomputed at each of the 251 dates when the set of active jurisdictions (or a label) changes: region minus everything active. Consecutive intervals with the same geometry and label are merged. Each piece is labelled by region and date:

   | Region | Labels (start dates) |
   |---|---|
   | east (1783 US area) | "Outside US/colonial jurisdiction (Indigenous lands; contested British/French claims)" → 1763-02-10 "British territory (outside colonial counties)" → 1776-07-04 "Disputed: British claim / state charter claims" |
   | florida | Spanish Florida → 1763-02-10 British Florida → 1783-09-03 Spanish Florida (until AHCB 1819-02-22) |
   | West Florida strip | generic → 1699-05-01 French Louisiana (Gulf coast) → 1763 British West Florida → 1783 Spanish West Florida (until AHCB Orleans Terr. 1804-10-01) |
   | louisiana | generic → 1682-04-09 French Louisiana → 1763-02-10 Spanish Louisiana → 1800-10-01 "Louisiana (retroceded to France 1800; Spanish-administered)" (until 1803-04-30) |
   | redriver | generic → 1670-05-02 Rupert's Land (British, HBC) (until AHCB 1804) |
   | texas / cession / gadsden | New Spain (Spanish claim) → 1821-09-27 Mexico (until 1836 / 1848 / 1853) |
   | oregon | "Outside … (Pacific Northwest)" → 1790-10-28 "Pacific Northwest (contested British/Spanish/US claims)" (until AHCB 1804) |
   | alaska | "Outside … (Alaska Native lands)" → 1784-08-14 Russian America (until 1867-03-30) |
   | hawaii | Hawaiian Islands (independent chiefdoms) → 1795-05-01 Kingdom of Hawaii → 1893-01-17 Provisional Government → 1894-07-04 Republic of Hawaii (until 1898-07-07) |

5. **Overlay robustness.** mapshaper's `-dissolve`, `-clip` and `-erase` silently returned empty results on layers containing overlapping copies or many coincident edges. So each union is a separate `-dissolve2` run, and each overlay (clip to the outline, minus New Haven, context) is a single-layer `-mosaic` whose non-overlapping tiles are then reassembled. A geometry that loses no tile keeps its original vertices.
6. **Simplification**: every feature goes into one mapshaper layer (so shared borders become shared arcs) with `-simplify percentage=30% keep-shapes` (Visvalingam/weighted, mapshaper 0.7.89) and TopoJSON `quantization=100000` (~125 m grid). The input is already the AHCB 0.01° (≈1 km) generalisation, roughly 1:2.5M. Shapes stay recognisable at ~1000 px for the whole US and at ~4× zoom on the colonial North-East. Set `GEO_SIMPLIFY` to change the level: 6% gives 290 KB but drops the Chesapeake detail; unsimplified is 700 KB.

## Projection recommendation

Use **`d3.geoAlbersUsa()`** for the US map; it works with every layer. The AlbersUsa insets are chosen by location, not by attribute, so every Alaska polygon (Alaska Native lands context → Russian America 1784–1867 → Alaska Department 1867 → District 1884 → Territory 1912 → State 1959) and every Hawaii polygon (chiefdoms → Kingdom → Republic → Annexation 1898 → Territory 1900 → State 1959) renders in the standard insets. This was checked in the 1610, 1790, 1880, 1900, 1912, 1959 and 2024 renders. AHCB has no Aleutian parts west of 180°, so nothing wraps.
Caveats:
- AlbersUsa draws nothing outside its three insets. Puerto Rico and the other territories in `us_states_modern` are invisible with it, and AHCB has no PR at all.
- `projection(point)` returns `null` outside the insets, so clip flow-line endpoints first.
- For one combined world/origins map, use a single world projection such as `d3.geoNaturalEarth1` or `d3.geoEqualEarth` instead of trying to place AlbersUsa insets.

If PR or custom insets are ever needed, build the AlbersUsa pattern by hand: `geoConicEqualArea` (lower 48) plus `geoConicEqualArea`/`geoMercator` insets, with a multiplexed stream as in d3's `albersUsa` source.

## World crosswalk (`build_world.mjs`)

- world-atlas ids (ISO 3166-1 numeric) are joined to world-countries `ccn3`. That gives `iso3 = cca3` and `name = name.common`; the original Natural Earth name stays in `ne_name`.
- No ISO code: Kosovo gets `iso3 = XKX` (the World Bank/EU user-assigned code; world-countries' UN code `UNK` is mapped to `XKX` in the CSV too). N. Cyprus and Somaliland (110m and 50m), and Indian Ocean Ter. and Siachen Glacier (50m only), have blank `iso3`.
- CSV `lon,lat` is the spherical centroid of the country's largest polygon in the 1:50m geometry, so France = metropolitan France and the US = lower 48. That holds for 236 rows; 14 tiny territories absent from NE 1:50m use world-countries `latlng`.
- `continent` = world-countries `region`, except Americas is split into North America (incl. Caribbean & Central America) and South America, and Antarctic is renamed Antarctica. `subregion` = world-countries `subregion`. Russia's region is Europe there.

## Verification

`verify_us_historical.mjs` passes with no errors. It checks:
- every listed id exists and is valid on July 1;
- every valid id is listed;
- no inverted rings;
- required properties are present;
- for all 160 distinct July-1 sets, jurisdictions + context tile the modern outline (9,302,862 km²) with < 0.2 % deviation, and no context polygon overlaps a jurisdiction.

Rendered PNGs (AlbersUsa, July 1) were inspected for 1610, 1650, 1700, 1750, 1776, 1783, 1790, 1803, 1810, 1820, 1840, 1850, 1860, 1870, 1880, 1900, 1912, 1959 and 2024, plus North-East close-ups for 1650/1700/1750/1776, a black-background "gap" render (1700, 1790, 1850: no slivers visible) and the two world maps. They are in the session scratchpad (`…/scratchpad/geo_renders/`), not in the repo; regenerate with `node render_checks.mjs <dir> [years] [--proj=albersusa|conic|ne|gulf|west] [--gaps]`.
What the renders show:
- **1610**: Virginia only, with Spanish Florida/New Spain and generic context.
- **1700**: MA Bay (incl. Maine), NH, RI, CT, NY, East/West Jersey, DE, PA, MD, VA, Carolina N/S; French Louisiana.
- **1776**: 13 colonies; British territory west; Spanish Louisiana.
- **1803**: Ohio, Indiana Terr., Mississippi Terr., Louisiana Purchase, Spanish Florida/West Florida.
- **1850**: Deseret over the Mexican Cession; Texas with its claim strip; Minnesota and Oregon territories.
- **1880**: Dakota, Indian, Wyoming territories; Alaska Department; Kingdom of Hawaii context.
- **1912**: Arizona/New Mexico states; Alaska District; Hawaii Terr.
- **1959**: Alaska a state, Hawaii a territory.

## Known inaccuracies and limitations

- **Colonial extents are AHCB organised (county) areas**, not charter claims. The context label for the rest ("Indigenous lands; contested British/French claims", "British territory …") is deliberately generic. Before 1763 the label does not separate the French-controlled Illinois Country from British claims.
- **Approximations** (table above): early Virginia, Plymouth, MD, RI, CT, NJ, DE, SC, GA and 1664–83 New York reuse a later AHCB extent. New Netherland, New Sweden and New Haven are synthesised from later AHCB counties; New Netherland includes eastern Long Island, which was English-settled.
- **Not represented**:
  - Popham Colony (1607–08);
  - Gorges's Province of Maine before 1652;
  - NH towns before 1679 (AHCB puts them under Massachusetts);
  - Dominion of New England (1686–89);
  - Spanish/French/Russian/Hawaiian internal subdivisions;
  - Native nations' territories as jurisdictions (they are only named generically in context labels);
  - US territories outside the 50 states + DC.
- **AHCB conventions kept as they are**:
  - US-claimed areas are drawn from the claim date (Louisiana Purchase from treaty date 1803-04-30; West Florida in Orleans Territory from 1804; Oregon Country from 1804);
  - Virginia covers the whole Northwest in 1783–84;
  - the Texas Republic includes its full Rio Grande claim.
  - Overlapping claims are drawn as overlapping polygons, so draw them semi-transparent or in a fixed order. Overlaps found on July-1 snapshots:
    - CT/RI 1662–64; DE/MD 1667–85; New Netherland/MD and /MA 1674; MD/PA 1681–85; NC/SC 1730–34;
    - CT/PA, CT/NY, PA/VA 1774–82 (Westmoreland, Yohogania etc.); NH, NY / Vermont Republic 1781;
    - CT Western Reserve / NW Terr. 1789–99; Toledo Strip (MI Terr./Ohio 1805–36, IN Terr./Ohio 1803–04);
    - AL/MS 1818–20; Texas Republic / Arkansas 1836–39; Indian Terr. / Texas incl. Greer County 1836–1889; OK Terr. / Texas 1890–95; Iowa / Missouri (Honey War) 1839–48;
    - Deseret / Mexican Cession, Oregon Terr., Texas, Unorganized Federal Terr. 1850; Michigan / Wisconsin 1909–25.
- **Context dates** follow the regions above. Where AHCB coverage starts later than the real transfer (e.g. Florida transferred 1821 but AHCB starts 1819-02-22, the Adams–Onís signing), the AHCB date wins. The 5,500 km² central-Colorado leftover is labelled generically throughout.
- **Detail**: 0.01° source generalisation plus 30 % simplification. Small coastal islands are simplified; tiny islets are kept with `keep-shapes`. The two data sources share the same coastline vertices (the AHCB state file is derived from the county file), so colonial and later shapes line up exactly.
